# Evidências do desenvolvimento

Esta pasta preserva capturas, logs curtos e resultados que sustentam as explicações do artigo. A primeira versão construída e executada está em [2026-10-23](2026-10-23/README.md), com relatório, campanha por botões e demonstração.

Para cada resultado, registrar a data, o objetivo, a etapa ou revisão do código, os comandos e as versões relevantes. Quando houver uma ROM, incluir seu identificador ou hash para relacionar a captura ao artefato testado.

Organizar os arquivos em subpastas com data e assunto e vinculá-los ao diário. O registro deve explicar o resultado esperado, o observado e as limitações do teste. Uma captura no emulador comprova aquele teste; eventual validação em console físico terá registro próprio.

Manter comandos e saídas úteis sem informações privadas ou caminhos pessoais absolutos. Arquivos temporários de construção pertencem a `build/` ou `dist/`; evidências selecionadas para explicar o desenvolvimento pertencem a esta pasta.
